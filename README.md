# NumPy Playground

Personal practice repository for mastering NumPy — the foundation of numerical computing in Python.

## Topics Covered

- Array Creation
- Shape, Size, NDIM
- Indexing & Slicing
- Vectorized Operations
- Aggregations & Statistics
- Reshape
- Stacking (`hstack`, `vstack`)
- Random Module (`seed`, `choice`)
- Case Study

## How to Use

1. Open notebooks in order
2. Run and experiment with the code
3. Try modifying values and observe results

## Structure

```
numpy-playground/
├── 01 to 16 numbered practice notebooks
└── Numpy_Case_Study_Clean.ipynb
```

## Learning Goal

Build strong intuition for:
- Multi-dimensional arrays
- Broadcasting
- Efficient numerical computations
