# NumPy Playground

A structured practice repository focused on developing a strong foundation in **NumPy**, the core numerical computing library in Python and a fundamental building block for Machine Learning and Data Science.

---

## Overview

This repository contains carefully organized Jupyter notebooks covering essential NumPy concepts. The material progresses systematically from array creation to advanced operations, with dedicated practice sets and a clean case study.

The goal is to build both conceptual clarity and practical fluency required for data analysis and machine learning workflows.

---

## Learning Objectives

By working through this repository, learners will be able to:

- Create and manipulate multi-dimensional arrays efficiently
- Perform indexing, slicing, and broadcasting operations
- Apply vectorized operations instead of explicit loops
- Compute statistical aggregations and summary metrics
- Use stacking and random number generation effectively
- Solve small end-to-end numerical problems using NumPy

---

## Topics Covered

| Module | Topics |
|--------|--------|
| Array Fundamentals | Array creation methods, shape, size, ndim |
| Access & Modification | Indexing, slicing, advanced selection |
| Computation | Vectorized operations, broadcasting |
| Statistics | Aggregations (sum, mean, min, max, std, etc.) |
| Advanced Tools | hstack, vstack, random module, seeding |
| Application | Practice sets + Clean case study |
