## Overview

This repository contains carefully sequenced Jupyter notebooks that take a learner from basic array creation to practical numerical problem-solving.  
The focus is on **conceptual clarity + hands-on fluency**, not just syntax memorization.

Every notebook is designed so that a serious student can demonstrate:
- Systematic learning
- Ability to write vectorized code
- Understanding of how NumPy underpins modern data science and ML pipelines

---

## Learning Objectives

After completing this repository, a learner will be able to:

- Create and manipulate multi-dimensional NumPy arrays efficiently
- Perform advanced indexing, slicing, and boolean selection
- Replace explicit loops with vectorized operations and broadcasting
- Compute statistical aggregations and summary metrics
- Use stacking, random number generation, and seeding correctly
- Solve small end-to-end numerical case studies using pure NumPy

---

## Topics Covered

| Module | Topics |
|--------|--------|
| **Array Fundamentals** | Array creation methods, `shape`, `size`, `ndim`, `dtype` |
| **Access & Modification** | Indexing, slicing, advanced selection |
| **Computation** | Vectorized operations, broadcasting |
| **Statistics** | Aggregations (`sum`, `mean`, `min`, `max`, `std`, etc.) |
| **Advanced Tools** | `hstack`, `vstack`, random module, seeding |
| **Application** | Multiple practice sets + clean case study |

## How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/shivamkumar98017/numpy-playground.git
   cd numpy-playground
   ```
2. Open the notebooks **in sequence** using Google Colab or Jupyter Notebook.
3. Execute every cell carefully and experiment by changing values.
4. Attempt the practice notebooks independently before looking at solutions.
