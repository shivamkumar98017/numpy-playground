# NumPy Playground 🧮

Personal practice repository focused on mastering **NumPy** — the core library for numerical computing in Python and a foundation for Machine Learning.

---

## 📌 Overview

This repository contains hands-on Jupyter notebooks covering essential NumPy concepts from basics to intermediate level. Each notebook is designed for active practice and experimentation.

---

## 📚 Topics Covered

| # | Topic | Description |
|---|-------|-------------|
| 01-02 | Array Creation | Creating arrays using different methods |
| 03 | Shape, Size, NDIM | Understanding array dimensions and attributes |
| 04 | Indexing & Slicing | Accessing and modifying array elements |
| 05-06 | Vectorized Operations | Element-wise operations without loops |
| 07-08 | Aggregations & Statistics | Sum, mean, min, max, std, etc. |
| 09-14 | Practice Sets | Multiple practice notebooks for reinforcement |
| 15 | Stacking & Random | `hstack`, `vstack`, `seed`, `choice` |
| 16 | Revision | Quick revision of key concepts |
| 17 | Case Study | Clean end-to-end NumPy case study |

## 🚀 How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/shivamkumar98017/numpy-playground.git
   ```
2. Open notebooks in **Google Colab** or Jupyter Notebook
3. Run cells in order and experiment by changing values
4. Practice writing your own examples after each topic
